# NayoGuildBridge

Клиентский Fabric-мод для нормального отображения bridged сообщений в гильд-чате.

## Что делает мод

- Чисто форматирует сообщения от bridge-ботов в `Guild`.
- Определяет источник по маркерам (`[TG]`, `.`, и т.д.) и подставляет нужный префикс.
- Красит имя отправителя отдельно от текста.
- Есть стиль ника через `§` коды или обычный цвет.
- Подсвечивает твой ник и слова по правилам (`слово=§коды`).
- Фильтрует мусор через блоклист.
- Может отправлять/получать сообщения через backend (`/api/ingest` и `/api/poll`).

## Актуальные версии

- Minecraft: `1.21.9` – `1.21.11` (один jar)
- Java: `21`
- Fabric Loader: `0.18.4+`

## Установка

1. Установи Fabric Loader.
2. Закинь `NayoGuildBridge` и зависимости в папку `mods`.
3. Запусти игру.
4. Открой меню мода (по клавише `Right Shift` или командой `/bridge`).

## Конфиг

Конфиг создается автоматически в:

- `config/chatbridge.json`

## Удалённое подключение и использование данных

NayoGuildBridge использует удалённый API и WebSocket-подключения для обеспечения работы моста (bridge) между Minecraft, Discord и веб-сайтом моста.

### Используемые адреса

**HTTP API:**

* [https://api.fiokem.cc](https://api.fiokem.cc)
* [https://api.2297211.xyz](https://api.2297211.xyz)

**WebSocket:**

* wss://api.fiokem.cc/ws
* wss://api.2297211.xyz/ws

### Для чего используется подключение

Удалённое подключение используется для:

* Отправки и получения сообщений моста.
* Просмотра изображений из Discord прямо в игре.
* Ответа на сообщения моста и их цитирования.
* Синхронизации данных гильдейского моста.

### Какие данные передаются

Мод может передавать:

* Никнейм Minecraft.
* Содержимое сообщений.
* Информацию о гильдии.

Мод **не собирает** пароли, платёжную информацию, файлы или другие персональные данные.
